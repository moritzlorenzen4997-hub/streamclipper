StreamClipper

A personal desktop tool for creating short-form highlight clips.

StreamClipper is a desktop application that runs locally on the operator's own Windows computer. It watches public live streams, detects highlight moments from chat activity and audio, cuts them into short vertical clips with captions and a visible credit to the original streamer, and queues them for manual review.

How TikTok is used

  • Login Kit: the operator signs in once with their own TikTok account to authorize the app.
  • Content Posting API (video.publish): after the operator manually approves a clip, the app uploads it to the operator's own TikTok account with a caption that credits the original creator.
  • user.info.basic: used only to identify the authorized account.

Nothing is posted without explicit approval. The app does not read, collect or store data about other TikTok users.
